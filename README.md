# Інформаційна система університету — лабораторна робота №4

Проєкт використовує звичайні HTML, CSS і JavaScript без сторонніх бібліотек та фреймворків.

## Файли
- `index.html` — сторінка та стилі (CSS вбудовано в HTML).
- `script.js` — дані, відображення таблиць, редагування, видалення, збереження та синхронізація.

## Реалізовані вимоги
1. Зміни зберігаються в `localStorage` після редагування або видалення.
2. Після повторного відкриття сторінки збережені дані відображаються автоматично.
3. Подія `storage` синхронізує зміни в інших вкладках тієї самої сторінки/джерела.
4. Поля «Викладач» у таблиці «Дисципліни» та «Дисципліна» у таблиці «Викладачі» редагуються через випадні списки, що формуються з даних інших таблиць.
5. Заборонено видаляти викладача, на якого посилаються записи дисциплін.
6. Значення в редагованих комірках можна змінити; Enter зберігає, Escape скасовує, перехід фокуса зберігає.

## Запуск
Завантажте `index.html` і `script.js` в одну папку та відкрийте `index.html` у браузері. Для найстабільнішої синхронізації вкладок можна запускати через локальний вебсервер або GitHub Pages. `localStorage` залежить від джерела сторінки: вкладки мають бути відкриті з одного й того самого URL/джерела.
